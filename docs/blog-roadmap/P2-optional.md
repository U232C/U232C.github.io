# P2：可选扩展

P2 是按实际运营和使用需求选择的增强功能，不作为博客正常运行的前置条件。

- [ ] 正式启用并完善 Giscus：配置评论服务，并处理主题同步、加载状态和失败反馈。
- [ ] 隐私友好的访问统计：了解访问趋势和热门内容，同时减少不必要的数据采集。
- [ ] 阅读历史与本地收藏：使用本地存储帮助读者保留浏览和收藏记录。
- [ ] 分享按钮：提供复制链接和常用平台分享入口。
- [ ] Atom 和 JSON Feed：在 RSS 之外提供更多标准化订阅格式。
- [ ] Webmention：支持站点之间的引用、回复和互动通知。
- [ ] PWA 与离线阅读：支持安装博客并缓存适合离线阅读的内容。
- [ ] 自动生成社交分享图：根据文章元数据生成统一风格的分享图片。
- [ ] 多语言和多作者能力：按未来内容规模扩展语言、作者信息和内容归属。
- [ ] GitHub 在线编辑入口：为文章提供跳转到 GitHub 编辑页面的快捷方式。
- [ ] 可选 CMS 管理界面：在保留静态输出的前提下按需增加可视化内容管理入口。
