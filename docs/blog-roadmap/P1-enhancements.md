# P1：体验增强

P1 用于在核心能力稳定后，完善内容维护、阅读体验、SEO、订阅和工程质量。

- [ ] 落地 `updated`、`pinned`、`banner` 元数据：让已有字段在页面展示和内容排序中产生明确行为。
- [ ] 旧链接别名与重定向：为更名后的文章保留可访问的历史地址。
- [ ] 搜索高亮、摘要、状态和 URL 同步：增强结果辨识度，并让搜索条件可恢复和分享。
- [ ] 移动端文章目录：为窄屏设备提供可折叠的长文导航入口。
- [ ] 图片尺寸、图注、加载与失败处理：降低布局偏移并改善图片内容的语义和异常体验。
- [ ] 全站 canonical、Open Graph 和结构化数据：统一公开页面的搜索与社交分享元数据。
- [ ] favicon、默认分享图等站点资产：补齐浏览器图标和缺省社交分享视觉资源。
- [ ] RSS 元数据与订阅策略：完善更新时间、分类、封面以及文章和日记的收录规则。
- [ ] 内容、链接、资源、slug 和生成结果检查：在构建阶段发现无效引用、重复路径和内容泄漏。
- [ ] TypeScript 类型检查脚本：提供独立且可在 CI 中运行的严格类型检查命令。
